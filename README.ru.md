<h1 align="center">Linary</h1>

<p align="center">
  Дневник для Linux, который работает с папкой синхронизации Diarium.<br>
  Читает и редактирует дневник прямо в папке синхронизации Dropbox — правки доходят до телефона.

## Отказ от ответственности

Linary — независимый проект, он не связан с разработчиком Diarium и не поддерживается им; «Diarium»
упоминается только чтобы указать, с какой папкой синхронизации работает Linary.

Linary распространяется **«как есть»**, без каких-либо гарантий (см. [лицензию](LICENSE)). Вы пользуетесь
им на свой риск: автор не отвечает за потерю или повреждение записей дневника и любой другой ущерб.
Делайте резервные копии дневника (см. [Безопасность](#безопасность)).

## Возможности

- **Календарь** с миниатюрами фото, несколькими записями в день и отметкой сегодняшнего дня.
- **Лента, поиск, теги, «В этот день»** и галерея **вложений**.
- **Просмотр**: форматированный текст, кликабельные ссылки, фото, теги, оценка, геометка; просмотр фото на весь экран.
- **Редактор** как на телефоне:
  - форматирование — жирный, курсив, подчёркнутый, зачёркнутый, списки, цвет текста и маркер, ссылки;
  - оценка, «Вставить время» (`Ctrl+T`), отмена и повтор;
  - несколько записей в день, новые записи, удаление с подтверждением.
- **Фото**: из файла, скриншот через `Ctrl+V` или перетаскиванием. Картинки уменьшаются и сохраняются
  в JPEG так же, как это делает телефон. Фото можно переставлять, делать обложкой дня (её показывает
  календарь) и скачивать в файл. Ленту вложений можно свернуть.
- **Синхронизация с телефоном** через папку Dropbox. Правки с телефона подхватываются сами.
- Горячие клавиши работают и в латинской, и в русской раскладке.
- **Экран блокировки**: по желанию приложение блокируется после заданного времени бездействия и при запуске,
  открывается PIN-кодом.
- **Значок в трее**; закрытие окна оставляет приложение работать в трее. Запускается только одна копия.
- Русский и английский интерфейс, светлая и тёмная тема, запоминаются размер и положение окна.

## Что нужно

- Linux x86_64 (разрабатывалось на Manjaro KDE, должно работать в любом окружении).
- Diarium на другом устройстве с **синхронизацией через Dropbox** и клиент Dropbox на компьютере,
  который синхронизирует папку `Приложения/Diarium` (`Apps/Diarium`).
- **Сквозное шифрование (E2EE) в Diarium должно быть выключено** — оно пока не поддерживается.
- **Ключ синхронизации** — см. ниже.
- По желанию: `kdialog` (KDE) или `zenity` (GNOME, XFCE и др.) для системных диалогов выбора файлов.

Можно открыть и файл резервной копии `.diary` — только для чтения.

## Ключ синхронизации

Файлы в папке синхронизации Diarium зашифрованы. **Ключ в Linary не входит**, и проект не даёт его
и не объясняет, как его получить: об этом попросил разработчик Diarium, и Linary уважает эту просьбу.
Пожалуйста, не спрашивайте ключ в Issues — такие запросы будут закрываться.

Без ключа Linary не может открыть папку синхронизации. Если ключ у вас уже есть, введите его на экране,
который Linary покажет при первом запуске, или позже в **Настройки → Синхронизация**. Он хранится только
в настройках Linary на вашем компьютере (`~/.java/.userPrefs/linary`) и больше нигде не показывается.

Без ключа можно открыть резервную копию `.diary`, выгруженную из Diarium, если она не зашифрована.
Резервные копии открываются только для чтения: изменить записи и передать правки на телефон так нельзя.

## Установка

В каждом [релизе](https://github.com/belkevglaz/linary/releases/latest) есть готовые пакеты для x86_64.
В каждый входит своя среда Java, больше ничего ставить не нужно.
В командах ниже версия `2.0.0` — подставьте ту, которую скачиваете.

### Arch Linux / Manjaro

```bash
curl -LO https://github.com/belkevglaz/linary/releases/download/v2.0.0/linary-2.0.0-1-x86_64.pkg.tar.zst
sudo pacman -U linary-2.0.0-1-x86_64.pkg.tar.zst
```

Приложение ставится в `/opt/linary`, появляются команда `linary` и ярлык в меню приложений.
Обновить — так же поставить пакет новой версии. Удалить: `sudo pacman -R linary`.

### Debian / Ubuntu / Linux Mint

```bash
curl -LO https://github.com/belkevglaz/linary/releases/download/v2.0.0/linary_2.0.0_amd64.deb
sudo apt install ./linary_2.0.0_amd64.deb
```

Удалить: `sudo apt remove linary`.

### Fedora / openSUSE

```bash
curl -LO https://github.com/belkevglaz/linary/releases/download/v2.0.0/linary-2.0.0-1.x86_64.rpm
sudo dnf install ./linary-2.0.0-1.x86_64.rpm        # openSUSE: sudo zypper install ./linary-2.0.0-1.x86_64.rpm
```

Удалить: `sudo dnf remove linary`.

### AppImage (любой дистрибутив)

```bash
curl -LO https://github.com/belkevglaz/linary/releases/download/v2.0.0/linary-2.0.0-x86_64.AppImage
chmod +x linary-2.0.0-x86_64.AppImage
./linary-2.0.0-x86_64.AppImage
```

AppImage нужен FUSE 2: `sudo pacman -S fuse2` в Arch/Manjaro, `sudo apt install libfuse2` в Ubuntu 22.04
(`libfuse2t64` в 24.04 и новее). Сам в меню приложений он не добавляется — это умеют AppImageLauncher
или Gear Lever. Удалить — просто удалить файл.

### Архив (любой дистрибутив)

```bash
curl -LO https://github.com/belkevglaz/linary/releases/download/v2.0.0/linary-2.0.0-x86_64.tar.gz
mkdir -p ~/.local/opt
tar -xzf linary-2.0.0-x86_64.tar.gz -C ~/.local/opt
~/.local/opt/linary/bin/linary
```

Ярлык в меню не создаётся. Удалить — удалить папку `~/.local/opt/linary`.

### Проверка скачанного файла

В каждом релизе есть `SHA256SUMS`. Положите его рядом со скачанным файлом и выполните:

```bash
sha256sum -c --ignore-missing SHA256SUMS
```

### Сборка из исходников

Для сборки нужен JDK 17+.

```bash
git clone https://github.com/belkevglaz/linary.git
cd linary

./gradlew run                                       # запустить без установки
./gradlew run --args="$HOME/Dropbox/Apps/Diarium"   # ... и сразу открыть папку или файл .diary

./packaging/install.sh                              # установить для текущего пользователя: ~/.local/opt, ярлык в меню
./packaging/uninstall.sh                            # удалить (настройки и резервные копии останутся)

cd packaging/arch && makepkg -si                    # Arch / Manjaro: собрать и поставить пакет pacman
```

Настройки хранятся в `~/.java/.userPrefs/linary`, резервные копии дневника —
в `~/.local/share/linary/backups`; при удалении приложения они остаются.

## Использование

При первом запуске приложение ищет `~/Dropbox/Apps/Diarium` или `~/Dropbox/Приложения/Diarium`.
Если папки там нет, нажмите кнопку с папкой и выберите файл `v4_database` в папке синхронизации
(или резервную копию `.diary`). Выбор запоминается.

| Где | Клавиши | Действие |
|---|---|---|
| Главное окно | `Ctrl+N` | Новая запись |
| | `Ctrl+R` | Перечитать |
| | `Ctrl+F` | Поиск |
| | `PgUp` / `PgDn` | Предыдущая / следующая запись |
| Везде | `Ctrl+L` | Заблокировать сейчас (если блокировка включена) |
| | `Ctrl+Q` | Выйти из приложения |
| Редактор | `Ctrl+S` | Сохранить |
| | `Ctrl+T` | Вставить время (`— 14:30 —`, для другого дня — с датой) |
| | `Ctrl+Z` / `Ctrl+Shift+Z`, `Ctrl+Y` | Отменить / повторить |
| | `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | Жирный / курсив / подчёркнутый |
| | `Ctrl+V` | Вставить текст или прикрепить картинку из буфера |
| | `Esc` | Закрыть (спросит, если есть несохранённые правки) |
| Просмотр фото | `←` / `→`, `Esc` | Предыдущее / следующее, закрыть |

Долгое нажатие или правый клик по дню в календаре — выбор одной из записей дня или новая запись.
Если задержать мышь над кнопкой-иконкой на две секунды, появится подсказка.

По умолчанию приложение показывает значок в системном трее, а закрытие окна (крестик или `Alt+F4`) прячет
его в трей, а не завершает приложение; клик по значку возвращает окно. Без значка в трее окно просто
сворачивается. Выйти: `Ctrl+Q`, пункт **Выйти** в меню значка или в Настройках. Оба поведения меняются
в **Настройки → Окно**. Значок работает по протоколу StatusNotifierItem (D-Bus) и выглядит родным в KDE Plasma,
XFCE, Cinnamon, LXQt и других; в GNOME нужно расширение «AppIndicator and KStatusNotifierItem Support».

Если запустить приложение, когда оно уже работает, вторая копия не откроется — на передний план выйдет уже открытое окно.

## Как это устроено

Синхронизация Diarium через Dropbox (формат **v4**) хранит всё в одной папке:

| Файл | Что внутри |
|---|---|
| `v4_database` | весь дневник: база SQLite, сжатая gzip и зашифрованная AES-256-CBC |
| `v4_Media/<GUID>` | каждое вложение, зашифрованное AES |
| `v4_mediaindex` | сжатый gzip JSON-список GUID вложений |

Без E2EE эти файлы зашифрованы ключом, который в проект не входит: Linary один раз спрашивает его
у вас и хранит в своих настройках (**Настройки → Синхронизация**).

Телефон сравнивает время изменения `v4_database` в Dropbox со временем своей последней синхронизации
и либо скачивает базу, либо выгружает свою, либо сливает их по записям. Linary достаточно
записать корректный `v4_database`: клиент Dropbox выгрузит его, и телефон заберёт изменения
при следующей синхронизации.

## Безопасность

Писать в чужой формат синхронизации рискованно, поэтому каждое изменение проходит одни и те же шаги:

1. Прочитать и расшифровать **текущий** `v4_database` с диска, а не копию на экране.
2. Проверить, что изменяемая запись не изменилась с момента открытия. Если её поменяли на другом
   устройстве, появится сообщение о конфликте: можно сохранить свою версию поверх или отменить.
3. Применить изменение, зашифровать и ещё раз проверить, что Dropbox за это время не заменил файл.
4. Сохранить **резервную копию** прежнего `v4_database` в `~/.local/share/linary/backups`
   (последние 20, в зашифрованном виде).
5. **Атомарно** заменить файл через временный `.~v4_database.tmp`, который Dropbox не синхронизирует.
6. Перечитать файл и проверить изменение. Если проверка не прошла, возвращается резервная копия.

Фото записываются в том же порядке, что и на телефоне: файлы в `v4_Media`, затем `v4_mediaindex`,
затем база. Удалённые фото только отвязываются в базе, а неиспользуемые файлы телефон удаляет
из Dropbox при своей синхронизации.

Остаётся одна лазейка: несколько миллисекунд между шагами 3 и 5. Если Dropbox запишет новую версию
с телефона ровно в этот момент, она будет перезаписана, и последние правки с телефона могут потеряться.
На практике это маловероятно, но не сохраняйте здесь запись в ту же секунду, когда синхронизируется телефон.

**Приватность.** Приложение не обращается в сеть: с Dropbox оно работает только через локальные файлы.
Расшифрованные данные, нужные во время работы (база на время чтения, вложения для внешнего плеера),
лежат в `$XDG_RUNTIME_DIR/linary` (в памяти, доступно только вам), а если его нет —
в `/tmp/linary-<user>`. Они удаляются при выходе, а остатки после падения — при следующем запуске.

## Блокировка

В **Настройки → Блокировка** (шестерёнка внизу боковой панели) можно включить **Блокировать при бездействии**, выбрать
время бездействия (1–60 минут) и задать PIN из 4–8 цифр. Тогда приложение запускается заблокированным
и блокируется снова, если ничего не делать заданное время; `Ctrl+L` блокирует сразу. После пяти неверных
PIN следующая попытка возможна только через 30 секунд.
В **Настройки → Экран блокировки** его можно сделать **сплошным** или **размытым**: за ним видно приложение, размытое настолько,
насколько вы выберете. По умолчанию при блокировке лента вложений сворачивается, а фото на весь экран
закрывается, чтобы снимки не просвечивали сквозь размытие; это можно отключить в Настройках.

Блокировка прячет дневник от посторонних за вашим компьютером, но это не шифрование: файлы дневника
на диске остаются как есть. Сам PIN хранится только в виде хэша PBKDF2 с солью.

### Забыли PIN

Выйдите из приложения (`Ctrl+Q` работает и на экране блокировки, или через меню значка в трее) и удалите настройки блокировки из `~/.java/.userPrefs/linary/prefs.xml`:

```bash
sed -i '/lock\./d' ~/.java/.userPrefs/linary/prefs.xml
```

После этого приложение запустится без блокировки. Остальные настройки и дневник не затрагиваются.

## Ограничения

- Синхронизация с E2EE не поддерживается.
- Проверено только с Dropbox. Другие облака, синхронизирующие ту же папку на диск, могут работать,
  но не проверялись.
- Редактируются текст, оценка и фото. Заголовки, теги, геометка и шаблоны показываются, но пока не редактируются.
- В Wayland оконный менеджер может не восстановить положение окна (размер восстанавливается).
